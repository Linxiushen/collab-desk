# 协作台 · Collab Desk 本地 Agent 工作台

协作台（Collab Desk）是一个运行在 Mac 上的中文群聊工作台。你可以把同一个问题交给分析员和复核员，查看各自署名的回答，也可以邀请自己平时使用的 Agent 加入。默认工作区、群记录和 Qwen3-4B 推理都在本机。这个项目根据 Pachat 的公开产品说明独立实现，使用自己的协议。

## 打开与使用

想直接与 Codex 聊天，在 Finder 里双击 **打开协作台Codex群.command**。输入 `@本地 Codex` 和问题，它会自动接单，并以自己的名字将回答发回群。启动器会自动准备这个成员。模型运行在本机，读取本次任务和群消息。要查实时天气、使用现有个人 Agent 的工具或项目资料，可按 [接入指南](AGENTS-CONNECT.md) 把相应客户端加入同一个讨论室。

在 Finder 里双击 **启动协作台.command**。启动器会打开带本机登录状态的浏览器页面。服务已在运行时，重复双击会重新打开浏览器。此处使用的地址为 `http://127.0.0.1:18473`。换浏览器、清除 Cookie 或会话过期后，重新双击启动器即可。

1. 打开「协作讨论室」，输入手头的问题。发送给全体时，内置分析员先回答，复核员会读到提问和这份答复再发言。
2. 需要单独分派时，点击输入框左下角的 **@ 全体成员** 选择收件人。新建讨论室可以让不同项目保留各自的历史。
3. 要接入已经在本机运行的 Codex、Claude Code 等客户端，点击「我的 Agent」旁的 **+**，为它生成专用令牌，并在「管理成员」里把它加入讨论室。详见 [Agent 接入指南](AGENTS-CONNECT.md)。

外部 Agent 会在自己的客户端读取待办并回帖。若想安排外部成员先分析、另一位再复核，分别指定收件人，等第一位的回复出现后再分派第二步。内置两位成员共享同一份 4B 模型权重，外部成员的模型和工具由各自的客户端决定。默认内置角色只处理聊天文字。

用完后双击 **关闭协作台.command**，即可停止网页服务和由本项目启动的模型，释放内存。下次打开会恢复原有讨论记录。

旧版数据目录和登录状态继续兼容；公开仓库不包含本机备份、日志或测试截图。

## 存储与环境

| 内容 | 本机位置 |
| --- | --- |
| 讨论室、消息和未完成的任务 | macOS Application Support 下的应用数据目录 |
| 网页服务日志 | 应用数据目录中的 server.log |
| 模型权重与推理日志 | `~/.cache/pachat-local/` |
| 已登录的外部 Agent 凭据 | `~/.pachat-local/profiles/` |

备份讨论记录时，先关闭工作台，再复制应用数据目录。该目录属于当前 macOS 用户，数据库以普通 SQLite 文件保存；默认路径沿用早期版本以保留已有记录。网页和模型都只监听回环地址，工作台按个人使用设计。要备份模型或 Agent 凭据，需要分别备份对应目录。

Apple Silicon macOS 已验证所需的 llama.cpp 和模型。复制到另一台 Mac 时需要 Python 3.9+，并按 [本机模型说明](MODEL.md) 准备推理环境。网页、数据库、CLI 和 MCP 适配器均使用 Python 标准库和原生浏览器功能。

## 终端入口

在本项目目录运行以下命令。

```sh
python3 launcher.py            # 启动并在默认浏览器打开工作区
python3 launcher.py --codex    # 直接进入本地 Codex 工作群
python3 launcher.py --no-open  # 仅启动服务
python3 launcher.py --stop     # 停止工作台和本项目的模型
```

项目范围、已核实的官方行为及本地版取舍见 [Pachat 项目评估](ASSESSMENT.md)。对 DS Bot 的功能、源码和部署评估见 [DS Bot 参考评估](DS-BOT-REVIEW.md)。

## 界面与运行状态

新版把讨论室导航、聊天和团队信息放在同一个工作台。左侧可按名称搜索讨论室并预览最近一条消息；右侧显示本群成员、职责及实际任务状态，窄屏下点击顶部成员按钮展开。消息可复制，来源链接可以点击，代码块单独排版。

模型准备期间任务会保留排队。内置成员的「正在回复」来自任务执行状态，外部成员显示等待回应；本地 Codex 的自动接单开关状态来自它的实际进程。接单进程运行不表示它正在生成答案。失败和中断会在群内留下明确提示。

此轮同时修复连续提问的上下文：后发问题能够读到前一轮稍后到达的回复，并排除未来轮次。验证命令如下，测试使用临时数据库。

```sh
python3 -B -m unittest -v test_store test_server test_codex_worker
```
